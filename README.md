## Как сохранять изменения на GitHub

**В VS Code:** панель **Source Control** (`Ctrl+Shift+G`) → напиши, что изменилось (например, «Конспект лекции 3 по математике») → **Commit** → **Sync Changes**.

**В терминале** (в этой папке):
```bash
git add .
git commit -m "Конспект лекции 3 по математике"
git push
```

Сохраняй так после каждой пары или хотя бы раз в неделю: GitHub — это резервная копия и история всех версий.

## Правила

- Репозиторий **публичный**: его видят все. Материалы преподавателей (презентации, PDF) без их разрешения сюда не клади — или сделай репозиторий приватным: на GitHub **Settings → General → Danger Zone → Change visibility**.
